# GMAT PrepMaster Pro 🎯
### Comprehensive GMAT Study Application & Error Log with 1,080 Questions

**GMAT PrepMaster Pro** is a modern, high-performance study platform designed to help you achieve a 705+ on the **GMAT Focus Edition**. It features an extensive 1,080-question database across all three sections, an intelligent **Error Log & Mistakes Tracker**, an authentic **Official Exam Simulator**, interactive **Formula Vault**, and real-time **Performance Analytics**.

---

## 🚀 Quick Start

### Running the App:
Run the built-in server script with Python:
```bash
py server.py
```
This starts the local server and automatically opens your default browser at **`http://localhost:8080`**.

Alternatively, you can open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).

## 🌟 Key Features

### 1. 📚 1,080 Curated GMAT Question Bank
- **Quantitative Reasoning (380 Questions)**:
  - Arithmetic (Powers, Exponents, Roots, Remainders, Modular Arithmetic, Fractions, Ratios, Successive %)
  - Algebra (Quadratic Factoring, Inequalities, Absolute Values, Sequences & Series, Simultaneous Systems)

---

### 2. ❌ Deep Error Log & Mistakes Tracker (The Secret to a 700+ Score)
- **Automatic Attempt Logging**: Every question you answer logs your chosen choice, correct choice, time spent (seconds), and timestamp.
- **Mistake Categorization**: Tag each error with one click:
  - 🔢 *Calculation Slip*
  - 📐 *Concept / Formula Gap*
  - 🪤 *Fell for Trap Option*
  - ⏱️ *Time Pressure / Rushed*
  - 👓 *Misread Question Stem*
  - 🍀 *Lucky Guess / Unsure*
- **Reflection Notes**: Inline editable text area to write down your takeaway and what to do differently next time.
- **⚡ One-Click "Retry Missed Questions"**: Launch a targeted drill session containing only your past mistakes.
- **📥 CSV Export**: Export your entire error log to CSV with one click for Google Sheets or Excel tracking.

---

### 3. 🎓 Exam Simulator & Custom Practice Modes
- **Official GMAT Exam Simulation**:
  - Timed test mode (2 mins/question official pace).
  - Pacing color indicator (green < 105s, yellow 105-150s, red > 150s).
  - **Strike-Through Elimination**: Right-click, click the "Strike" button, or press `S` to cross off eliminated choices!
  - Flag / Bookmark questions for review.
- **Instant Practice Mode**:
  - Immediate step-by-step solution reveal.
  - **⚠️ GMAT Trap Alerts** highlighting common pitfalls and distractor patterns.

### 4. 📈 Performance Analytics & GMAT Focus Score Estimator
- **Score Scale**: Estimates your scaled score on the GMAT Focus 205-805 scale (and 60-90 section scales).
- **Topic Mastery Matrix**: Highlights your weakest areas so you know exactly where to focus.
- **Pacing Radar**: Compares average time spent on correct vs. incorrect questions.

- High-yield Quant formulas (Difference of Squares, Inradius, Harmonic Mean, Work-Rate, Modular Remainder).
- Verbal strategy patterns (Assumption Negation, Subjunctive trigger verbs, Dangling modifiers).

---

### 6. ⌨️ Keyboard Shortcuts
- **`A`, `B`, `C`, `D`, `E`**: Select answer choices.
- **`S`**: Toggle Strike-through elimination on selected choice.
- **`Space` or `→` (Right Arrow)**: Go to Next question.
- **`←` (Left Arrow)**: Go to Previous question.

---

### 7. 💾 Local Persistence & Data Freedom
- Built with **IndexedDB**, meaning zero backend database configuration is required.
- All your history, notes, attempts, and bookmarks stay permanently saved on your computer.
- Full **Export JSON** and **Import JSON** support under Settings.
